# China Broadnet for Home Assistant · 中国广电

把中国广电手机账户的实查读数放进 Home Assistant，用于仪表盘、Recorder 历史和自动化。这是独立社区项目，采用 MIT 许可。

## 0.1.0 开发预览

| 数据源 | 如何更新 | 验证状态 |
| --- | --- | --- |
| 手机号和短信验证码登录 | 在 HA 登录后每 8 分钟只读刷新 | 已用授权广电卡实测登录、余额和套餐余量接口 |
| 营业厅实查值 | 在官方营业厅查询，随后在 HA 界面录入 | 已用授权广电卡确认网页登录和账户查询。HA 自动化测试使用合成读数 |
| SmsForwarder | 局域网内推送符合本人配置模板的短信 | 实验性。转发表单有上游文档，解析与 HA 接收使用合成短信测试 |
| 网上营业厅会话 | 导入本人网页会话后，每 8 分钟只读刷新 | 实验性，使用网上营业厅内部协议 |

网上营业厅模式由 HA 原生异步客户端查询。手机号登录使用广电官方移动网页的短信认证协议。HA 只在用户提交登录表单或手动请求重发时发送验证码。短信推送还需要运行 SmsForwarder 的 Android 手机，可直接连接 HA，无需 Gotify 或 Tailscale。详见[数据源调查](docs/data-sources.md)。

## 安装

需要 Home Assistant Core **2026.10.0 或以上**。无需修改 `configuration.yaml`。

- **开发预览手动安装**：从包含集成的分支下载源码，将完整的 `custom_components/china_broadnet/` 复制到 HA 配置目录下的 `custom_components/`，然后重启 HA。
- **HACS 自定义仓库**：在 HACS 菜单进入「自定义仓库」，填写 `https://github.com/jeblove/ha-china-broadnet`，类别选择「集成」，下载 China Broadnet 后重启。[HACS 自定义仓库说明](https://www.hacs.xyz/docs/faq/custom_repositories/)

进入 **设置 → 设备与服务 → 添加集成**，搜索 **中国广电** 或 **China Broadnet**。支持简体中文和英文。为每张卡设置不同的别名，避免使用真实手机号。

### 手机号和短信验证码登录

1. 添加集成时选择「手机号和短信验证码登录」，填写别名和手机号。阅读广电官方协议，确认后提交。广电会发一条登录短信。
2. 输入短信验证码并提交。此登录入口当前无需图形验证码。HA 查询余额成功后创建实体。广电接受短信发送后显示 5 分钟有效期倒计时，60 秒后可手动重发。
3. 集成默认汇总能确认的本月通用包。打开配置项菜单的「重新配置」，可勾选其中任意几项。已有的手填名称作为原有选择保留。定向、赠送和结转包各自提供余量及到期时间。
4. 会话失效时，在 HA 的重新认证提示中为原手机号重新申请短信验证码。轮询不会发短信。

HA 配置项保存手机号、会话凭据和流量包设置，可能进入备份。短信验证码仅用于当前登录请求。

### 图形验证码备用登录（实验性）

从局域网访问 HA 并选择「图形验证码登录」。如果桌面官网向 HA 返回验证码图片，HA 会在表单内显示图片。填写手机号及图形验证码后，提交表单申请短信，再填入短信验证码。图片链接仅在局域网有效。表单从收到图片起显示两分钟倒计时，到零时隐藏验证码，提交过期图片的表单会获取新图。若官网向 HA 返回网页验证页，流程停在取图阶段。此时可以返回使用移动网页短信登录。

备用流程已通过合成响应测试。当前测试出口的原生 HTTP 请求仍被桌面官网的网页验证拦截，尚未完成真实备用登录。若移动网页今后启用图形验证码，需要核对其新的接口契约后接入现有图片显示流程。

### 导入网上营业厅会话（实验性）

1. 在可信电脑的浏览器正常登录 [中国广电网上营业厅](https://www.10099.com.cn/)，进入「个人中心 → 我的账户」。
2. 在该标签页的开发者工具中打开「控制台」，复制网页保存的两项会话状态。以下命令只读取本标签页并复制到剪贴板。

   ```javascript
   copy(JSON.stringify({
     broadnetUserPhoneInfo: sessionStorage.getItem("broadnetUserPhoneInfo"),
     broadnetUserSessionId: sessionStorage.getItem("broadnetUserSessionId")
   }))
   ```

3. 在同一标签页的开发者工具「网络」中，点击或重新进入「我的账户」，选择成功的 `qryBalanceFee` 请求。右键选择「复制 → 复制为 cURL (bash)」。
4. 在 HA 添加「网上营业厅会话」，填入会话 JSON，并将整段 cURL 粘贴到对应输入框。集成只读取 Cookie 和 User-Agent。流量包可在「重新配置」中选择。
5. HA 通过 `DataUpdateCoordinator` 每 8 分钟执行一次只读查询，并沿用广电在成功响应中更新的路由 Cookie。收到网页验证页时，读数变为不可用，下次自动重试推迟至一小时后。广电明确拒绝会话时，HA 会提示「需要重新认证」。若网页可查但 HA 持续收到验证页，请检查两者的网络出口。

会话 JSON 和复制的 cURL 都包含账号凭据。只粘贴到自己的可信 HA 实例，完成后清理剪贴板。它们由 HA 配置项保存，可能进入 HA 备份。当前仍需验证不同地区、套餐和网络下的长期稳定性。

### 录入营业厅实查值

1. 登录中国广电 App 或营业厅小程序，查看当前话费余额和本月套餐通用流量。
2. 添加集成时选择「录入营业厅实查值」，填入能确认的数值。余额填元，流量填十进制 GB。网上营业厅「我的账户」所示的 `G` 是二进制口径，乘以 1.073741824 可换算为 GB。未知项留空，例如只查到套餐通用流量剩余时，填写剩余项即可。
3. 下次查到新值后，打开该配置项的菜单，选择「重新配置」。填写余额会更新余额，填写任一流量项会替换整组流量，空白流量项变为不可用。完全不填某组会保留其上一份读数，直至过期。

### 接收短信（实验性）

1. 在本人广电号码上，通过当地客服确认是否会下发可用的查询短信。准备真实回执，核对发送人、流量类型、归属月份和单位进制。
2. 添加「接收转发短信」，输入实际发送人，并为余额或本月套餐通用流量填写完整模板。将短信中的金额连同「元」替换为 `{balance}`，将通用流量数值连同单位替换为 `{data_total}`、`{data_used}` 或 `{data_remaining}`。每种模板可选，各字段只能出现一次。模板其他文字按整条短信匹配。遇到未支持的动态字段、混合套餐或不明口径时，改用手动录入。
3. 从配置项菜单「重新配置」获取私密 Webhook 路径。在 SmsForwarder 创建 Webhook 通道，把该路径接在 HA 的局域网地址后。用 `POST`、默认表单参数、短信正文模板 `{{MSG}}`，自定义请求体和额外签名留空。预期字段为 `from`、`content` 和毫秒 `timestamp`。
4. 建立仅转发对应发送人、SIM 卡及查询回复关键词的规则。先用一条已核实的回执比对 HA 读数和官方页面，再用于自动化。

以下是**虚构模板示意**，实际填写时请使用本人收到的短信措辞。

```text
示例话费余额：{balance}
示例本月套餐通用流量：共{data_total}，已用{data_used}，剩余{data_remaining}
```

SMS 输入支持 B、KB、MB、GB 以及 KiB、MiB、GiB。含 i 的单位按二进制解释，其余按配置的进制解释，统一输出十进制 GB。例如二进制口径的 1024 MB 会显示为约 1.074 GB。进制无法确认时请先核实。可选配置仅映射当前月套餐通用流量，定向、结转、赠送和其他有效期的包不汇总。

## 传感器和刷新

| 传感器 | 单位 | 含义 |
| --- | --- | --- |
| 话费余额 | CNY | 账户余额，可为零或负数 |
| 当月消费 | CNY | 营业厅当月消费合计 |
| 上月已出账金额 | CNY | 上月账期折后费用合计。手机号登录会话需包含归属地区，旧会话可在下次重新认证时获取 |
| 本月套餐外费用 | CNY | 流量、语音和短信分别显示。三项都有读数时才显示合计 |
| 套餐名称 | 无 | 营业厅返回的当前资费套餐名称，每 6 小时更新 |
| 本月语音余量 | min | 可确认的本月套餐内语音分钟数 |
| 定向、赠送和结转包 | GB、时间戳 | 每条可识别资源独立显示余量及到期时间 |
| 本月套餐通用流量总量 | GB | 同一套餐、同一月份的通用额度 |
| 本月套餐通用流量已用 | GB | 来源明确提供的已用值 |
| 本月套餐通用流量剩余 | GB | 来源明确提供的剩余值 |
| 最近成功更新时间 | HA 时间戳 | HA 最近一次接受有效读数的时间 |

手动和短信模式分别保存余额和流量。有效推送立即更新，HA 在读数满 48 小时或本月流量跨北京时间月界时用单次事件让对应读数失效。网上营业厅模式在运行时每 8 分钟刷新，重载后重新查询。传感器可用于 Recorder 历史；余额和时间戳使用原生设备类别，流量使用测量型状态类别。

## 查询诊断和自动化

在设备的诊断区可以按「刷新营业厅读数」。一次查询开始后 60 秒内的重复点击会合并为一次。会话过期和网页验证退避期间，按钮会遵守现有查询限制。

在「设备与服务 → 中国广电」的配置项菜单选择「下载诊断」，可获取查询状态、缺失项和流量包排除原因的计数。导出只包含固定字段、可用性和计数。

「本月流量用量超前幅度」以百分点显示已用占比减去北京时间账期已过占比。例如已用 70%、账期已过 40%，实体值为 30。可以把它用作进度预警的监测实体。

### 安装提醒蓝图

在 HA 打开「设置 → 自动化与场景 → 蓝图 → 导入蓝图」，粘贴 [中国广电用量提醒](https://github.com/jeblove/ha-china-broadnet/blob/main/blueprints/automation/china_broadnet/usage_alert.yaml) 的 GitHub 地址。每种提醒创建一条自动化，选择对应传感器和通知动作，并为该提醒创建独立的「输入布尔值」助手。助手保留已提醒状态，异常解除后重新启用提醒。静默时段结束时，如果异常仍存在，蓝图会在下一次分钟检查发送提醒。支持低余额、低流量、流量用量超前和流量包到期提醒。

网上营业厅模式提供查询状态、余额最后成功时间和套餐余量最后成功时间。查询状态可区分会话过期、网页验证、查询失败和部分数据可用。

- 「预计流量可用天数」基于 Recorder 最近七天的本月通用流量记录。至少需要一天可比较的历史和实际增长。跨月、选包变化、用量回退或未启用 Recorder 时，传感器暂不可用。
- `china_broadnet_usage_spike` 在一小时内相同口径的已用流量增加达到 5 GB 时触发，包含 `entry_id`、`used_gb` 和 `window_seconds`。可在 HA 自动化中使用事件触发器连接通知。
- `china_broadnet_packages_changed` 在识别到包新增、移除、续期或有效期变化时触发，包含 `entry_id` 和 `changes`。首次成功查询建立基线。
- 「月末用量快照」保留最近 12 个有读数的账期。实体属性列出各账期的已用流量、当月消费和语音余量，及每个指标最后一次成功观察时间。删除配置项会删除本地快照。

## 常见问题

- **短信返回 200，实体没有更新**。无效发送人、不匹配模板、过旧请求和重复消息也返回 200。核对路径、完整模板、手机时钟和默认表单类型。发送时间与 HA 时钟相差超过 10 分钟会被忽略。时间戳是转发方提交时间，首次验收时请用刚收到的回执。
- **找不到 Webhook 或值一直不可用**。确认手机能直接访问 HA 的局域网地址，确认配置项已加载，且端口和协议正确。修改发送人、模板或进制会清除当前读数。换发地址后需同步更新 SmsForwarder。
- **套餐数值缺失**。来源可能只提供一部分数据，集成不会用差值或其他流量包补齐。
- **卸载**。先停用对应的 SmsForwarder 规则，再在 HA 删除配置项。Recorder 历史按 HA 自己的保留策略管理。

## 隐私

Webhook 路径包含可提交读数的密钥。仅用于受信任的局域网，避免记录完整 URL，泄露后在「重新配置」中换发路径。条件允许时使用 HTTPS。短信正文只在处理请求时使用，集成保存模板、设置、归一化读数、时间戳及去重摘要。配置和历史数据可能进入 HA 备份。不要在模板或问题报告中附真实手机号、验证码、Cookie、Token、Webhook 路径或完整个人账单。SmsForwarder 自身的历史和日志由手机端设置管理。

## 开发和路线图

使用 Python 3.14 创建虚拟环境并执行：

```bash
python -m pip install -r requirements-dev.txt
ruff check .
ruff format --check .
pytest -q
```

GitHub Actions 配置了 pytest、Ruff、Hassfest 和 HACS 校验。官方 HACS 校验器只接受公开仓库，因此该任务仅在公开仓库运行。贡献与复现方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。后续优先验证更多地区、套餐和长期会话稳定性。进度见 [TODO.md](TODO.md) 和 [CHANGELOG.md](CHANGELOG.md)。
