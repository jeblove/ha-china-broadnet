# China Broadnet for Home Assistant · 中国广电

把中国广电手机账户的实查读数放进 Home Assistant，用于仪表盘、Recorder 历史和自动化。这是独立社区项目，采用 MIT 许可。

## 0.1.0 开发预览

| 数据源 | 如何更新 | 验证状态 |
| --- | --- | --- |
| 营业厅实查值 | 在官方营业厅查询，随后在 HA 界面录入 | 已用授权广电卡确认网页登录和账户查询。HA 自动化测试使用合成读数 |
| 网上营业厅浏览器助手 | 在可信电脑运行浏览器助手，每 30 分钟向 HA 推送读数 | 实验性，使用已登录的官方网页会话 |
| SmsForwarder | 局域网内推送符合本人配置模板的短信 | 实验性。转发表单有上游文档，解析与 HA 接收使用合成短信测试 |
| 营业厅账号 API | 待研究 | 已观察官方网页内部查询，第三方认证、会话失效和数据口径仍待验证 |

自动更新可来自短信或单独运行的浏览器助手。使用手动入口只需 Home Assistant 和官方查询渠道。短信入口需要运行 SmsForwarder 的 Android 手机，可直接连接 HA，无需 Gotify 或 Tailscale。浏览器助手通过正常的网页操作执行只读查询，账号会话留在运行助手的电脑。详见[数据源调查](docs/data-sources.md)。

## 安装

需要 Home Assistant Core **2026.10.0 或以上**。无需修改 `configuration.yaml`。

- **开发预览手动安装**：从包含集成的分支下载源码，将完整的 `custom_components/china_broadnet/` 复制到 HA 配置目录下的 `custom_components/`，然后重启 HA。
- **HACS 自定义仓库**：当有权访问的仓库默认分支包含本集成后，在 HACS 菜单进入「自定义仓库」，填写 `https://github.com/jeblove/ha-china-broadnet`，类别选择「集成」，下载 China Broadnet 后重启。开发分支优先使用手动安装。项目处于预览阶段。

进入 **设置 → 设备与服务 → 添加集成**，搜索 **中国广电** 或 **China Broadnet**。支持简体中文和英文。为每张卡设置不同的别名，避免使用真实手机号。

### 录入营业厅实查值

1. 登录中国广电 App 或营业厅小程序，查看当前话费余额和本月套餐通用流量。
2. 添加集成时选择「录入营业厅实查值」，填入能确认的数值。余额填元，流量填十进制 GB。网上营业厅「我的账户」所示的 `G` 是二进制口径，乘以 1.073741824 可换算为 GB。未知项留空，例如只查到套餐通用流量剩余时，填写剩余项即可。
3. 下次查到新值后，打开该配置项的菜单，选择「重新配置」。填写余额会更新余额，填写任一流量项会替换整组流量，空白流量项变为不可用。完全不填某组会保留其上一份读数，直至过期。

### 通过浏览器查询网上营业厅（实验性）

选择「通过浏览器查询网上营业厅」，在「重新配置」取得私密 Webhook 路径。按[浏览器助手说明](tools/browser/README.md)启动助手。HACS 安装的是 HA 集成，助手从项目源码单独运行。助手每 30 分钟查询一次，失去会话或查询失败就停止，浏览器模式的读数在 90 分钟后失效。

### 接收短信（实验性）

1. 在本人广电号码上，通过当地客服确认是否会下发可用的查询短信。准备真实回执，核对发送人、流量类型、归属月份和单位进制。
2. 添加「接收转发短信」，输入实际发送人，并为余额或本月套餐通用流量填写完整模板。将短信中的金额连同「元」替换为 `{balance}`，将通用流量数值连同单位替换为 `{data_total}`、`{data_used}` 或 `{data_remaining}`。每种模板可选，各字段只能出现一次。模板其他文字按整条短信匹配。遇到未支持的动态字段、混合套餐或不明口径时，改用手动录入。
3. 从配置项菜单「重新配置」获取私密 Webhook 路径。在 SmsForwarder 创建 Webhook 通道，把该路径接在 HA 的局域网地址后。用 `POST`、默认表单参数、短信正文模板 `{{MSG}}`，自定义请求体和额外签名留空。预期字段为 `from`、`content` 和毫秒 `timestamp`。
4. 建立仅转发对应发送人、SIM 卡及查询回复关键词的规则。先用一条已核实的回执比对 HA 读数和官方页面，再用于自动化。

以下是**虚构模板示意**，实际填写时请使用本人收到的短信措辞。

```text
示例话费余额：{balance}
示例本月套餐通用流量：共{data_total}，已用{data_used}，剩余{data_remaining}
```

SMS 输入支持 B、KB、MB、GB 以及 KiB、MiB、GiB。含 i 的单位按二进制解释，其余按配置的进制解释，统一输出十进制 GB。例如二进制口径的 1024 MB 会显示为约 1.074 GB。进制无法确认时请先核实。可选配置仅映射当前月套餐通用流量，定向、结转、赠送和其他有效期的包不汇总。

## 传感器和刷新

| 传感器 | 单位 | 含义 |
| --- | --- | --- |
| 话费余额 | CNY | 账户余额，可为零或负数 |
| 本月套餐通用流量总量 | GB | 同一套餐、同一月份的通用额度 |
| 本月套餐通用流量已用 | GB | 来源明确提供的已用值 |
| 本月套餐通用流量剩余 | GB | 来源明确提供的剩余值 |
| 最近成功更新时间 | HA 时间戳 | HA 最近一次接受有效读数的时间 |

余额和流量独立保存。有效推送立即更新，HA 每五分钟检查一次数据是否过期。手动和短信读数超过 48 小时后不可用，本月流量还会在北京时间跨月后失效，最迟在下一次检查时更新。时间戳保留最近成功更新的时间。重新加载会读取已保存的读数。传感器可用于 Recorder 历史；余额和时间戳使用原生设备类别，流量使用测量型状态类别。

## 常见问题

- **短信返回 200，实体没有更新**。无效发送人、不匹配模板、过旧请求和重复消息也返回 200。核对路径、完整模板、手机时钟和默认表单类型。发送时间与 HA 时钟相差超过 10 分钟会被忽略。时间戳是转发方提交时间，首次验收时请用刚收到的回执。
- **找不到 Webhook 或值一直不可用**。确认手机能直接访问 HA 的局域网地址，确认配置项已加载，且端口和协议正确。修改发送人、模板或进制会清除当前读数。换发地址后需同步更新 SmsForwarder。
- **套餐数值缺失**。来源可能只提供一部分数据，集成不会用差值或其他流量包补齐。
- **卸载**。先停用对应的 SmsForwarder 规则，再在 HA 删除配置项。Recorder 历史按 HA 自己的保留策略管理。

## 隐私

Webhook 路径包含可提交读数的密钥。仅用于受信任的局域网，避免记录完整 URL，泄露后在「重新配置」中换发路径。条件允许时使用 HTTPS。短信正文只在处理请求时使用，集成保存模板、设置、归一化读数、时间戳及去重摘要。配置和历史数据可能进入 HA 备份。不要在模板或问题报告中附真实手机号、验证码、Cookie、Token、Webhook 路径或完整个人账单。SmsForwarder 自身的历史和日志由手机端设置管理。

## 开发和路线图

使用 Python 3.14 创建虚拟环境并执行：

```bash
python -m pip install -r requirements-dev.txt
ruff check .
ruff format --check .
pytest -q
```

GitHub Actions 配置了 pytest、Ruff、Hassfest 和 HACS 校验。官方 HACS 校验器只接受公开仓库，因此该任务仅在公开仓库运行。贡献与复现方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。优先收集有授权、已脱敏的短信回执并验证官方账号查询路径，之后再评估套餐名称、账单、独立流量包和发布。进度见 [TODO.md](TODO.md) 和 [CHANGELOG.md](CHANGELOG.md)。
